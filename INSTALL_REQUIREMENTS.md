# Installation Requirements

## For Your Computer Setup

Copy and paste this command in your terminal to install all required packages:

```bash
pip install streamlit pandas numpy scikit-learn xgboost lightgbm catboost plotly matplotlib seaborn folium streamlit-folium pyyaml flask
```

## Alternative: Install One by One

If the above doesn't work, try installing each package separately:

```bash
pip install streamlit
pip install pandas
pip install numpy
pip install scikit-learn
pip install xgboost
pip install lightgbm
pip install catboost
pip install plotly
pip install matplotlib
pip install seaborn
pip install folium
pip install streamlit-folium
pip install pyyaml
pip install flask
```

## For Python Environment

Make sure you have Python 3.11 or newer:
```bash
python --version
```

## Testing Installation

To test if everything is installed correctly:
```bash
python -c "import streamlit, pandas, numpy, sklearn, xgboost, lightgbm, catboost, plotly, matplotlib, seaborn, folium; print('All packages installed successfully!')"
```
